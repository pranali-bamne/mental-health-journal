# Mental Health Journal Website 🌱

A personal mental health journal website designed to encourage self-reflection, emotional awareness, and mindful journaling.  
This project focuses on simplicity, comfort, and user-friendly design.

## 🚧 Project Status
**In Development**  
This project is actively being worked on, with new features, UI improvements, and functionality added regularly.

## ✨ Features (Current & Planned)
- Journal writing section with a calming UI
- Emoji-based mood expression
- Save journal entries
- Responsive design for mobile & desktop
- Clean and minimal interface

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript 

## 📌 Purpose
This project is being developed as part of a learning journey and a personal initiative to build something meaningful around mental health and self-care.
